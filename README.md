# YouTube Trending Video Statistics

This repository contains the public YouTube Trending Video Statistics dataset
used for a Data Visualisation project.

## Dataset

Source:
Mitchell J. — Trending YouTube Video Statistics, 2017–2018

The dataset contains trending YouTube video statistics for 10 countries:

- Canada
- Germany
- France
- Great Britain
- India
- Japan
- South Korea
- Mexico
- Russia
- United States

The data includes video views, likes, dislikes, comments, tags,
publication date, trending date, category and other metadata.

## Project

The dataset will be used for a Data Visualisation project focused on
understanding patterns in YouTube trending videos across countries,
categories and engagement metrics.

## Data structure

Each country has its own CSV file:

`CAvideos.csv`, `DEvideos.csv`, `FRvideos.csv`, `GBvideos.csv`,
`INvideos.csv`, `JPvideos.csv`, `KRvideos.csv`, `MXvideos.csv`,
`RUvideos.csv`, `USvideos.csv`

Category mappings are provided as JSON files.

## Original source

The dataset was originally obtained from Kaggle:

Mitchell J. — Trending YouTube Video Statistics, 2017–2018.

This GitHub repository is used to make the dataset accessible to the
project's Docker-based data pipeline.
